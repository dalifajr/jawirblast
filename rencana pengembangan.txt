RANCANGAN PENGEMBANGAN SISTEM INFORMASI KAMPANYE BROADCAST WHATSAPP (JAWIRBLAST).

saya ingin langsung melakukan proses development pada server dev saya. jadi saya ingin menginstall langsung aplikasi ini kedalam server dengan install.sh untuk membantu proses penginstallan. saya juga akan memasang domain untuk ini.

jadi tolong buatkan install.sh yang berfungsi untuk menginstall project ini kedalam server, depedensi, paket-paket yang dibutuhkan juga harus terinstall.

saya juga mau ada panel control pada terminal vps saya nanti yang berguna untuk start, stop dan restart service, change domain, reset password admin, ubah key turnsitle cf, ubah bot api key telegram, dan command untuk update website.

saya sudah punya contoh programnya pada "D:\bot_tele_jualan"

TEKNOLOGI YANG DIGUNAKAN;
A. VPS UBUNTU 26 RAM 42GB 12CPUs
B. LARAVEL 13 FULLSTACK
C. BAILEYS API untuk jembatan website dengan whatsapp. repo github https://github.com/WhiskeySockets/Baileys
D. mySQL untuk database.
E. GITHUB untuk manajemen versi.
