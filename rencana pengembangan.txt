RANCANGAN PENGEMBANGAN SISTEM INFORMASI KAMPANYE BROADCAST WHATSAPP (JAWIRBLAST).

sistem ini ditujukan untuk user guna melakukan pengiriman pesan kampanye dalam jumlah tertentu ke nomor yang sudah ditentukan. 

user dapat mengirimkan pesan kepada db nomor whatsapp yang sudah ditambahkan oleh admin dengan banyak, dan kecepatan tertentu perpesan.

sistem dapat melakukan penautan akun whatsapp sebagai perangkat tertaut (desktop) pada sistem untuk digunakan sebagai sender.

sistem dapat melakukan pengiriman pesan ke nomor yang tersedia pada db dengan pesan yang dapat dikustomisasi admin.

sistem dapat melakukan tracking pesan, apakah sudah terkirim dan diterima nomor tujuan atau gagal, ditandai dengan centang 1 dan centang 2 lalu centang biru.

tambahkan dukungan multi language pada website, indonesia, english dan china. jadi teks jangan dihardcode.

user dapat mendaftar secara mandiri ke website.

untuk run project ini pada saat development, saya menggunakan laragon. sehingga untuk php dan mysql sudah tersedia.

TEKNOLOGI YANG DIGUNAKAN;
A. VPS UBUNTU 26 RAM 42GB 12CPUs
B. LARAVEL 13 FULLSTACK
C. BAILEYS API untuk jembatan website dengan whatsapp. repo github https://github.com/WhiskeySockets/Baileys
D. mySQL untuk database.
E. GITHUB untuk manajemen versi.
F. TELEGRAM bot untuk opsi login, dan notifikasi admin.
